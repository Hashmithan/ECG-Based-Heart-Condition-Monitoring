🚀 Overview

This repository contains the AI-based ECG analysis module developed for Lumofit, a wearable health and posture monitoring system.

The system processes real-time ECG signals and classifies heartbeats into normal and abnormal categories using machine learning techniques.

💡 Features
📊 Real-time ECG signal processing
🤖 AI-based heartbeat classification
📁 Automatic data logging (every 187 samples)
📉 Probability-based prediction output
🧠 Supports multiple heartbeat classes:
Normal (N)
Supraventricular (S)
Ventricular (V)
Fusion (F)
Unknown (Q)

📊 Datasets Used
MIT-BIH Arrhythmia Dataset
PTB Diagnostic ECG Database
🛠️ Tech Stack
Python
NumPy / Pandas
Scikit-learn / TensorFlow (depending on your model)
Signal Processing Techniques
